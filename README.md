# Technology Teaching Designer

An AI skill that helps primary and secondary teachers plan technology lessons and create teaching materials.

## Main functions

| Function | What it creates |
| --- | --- |
| **Curriculum maps** | A step-by-step teaching sequence with topics, prerequisites, platforms, lesson tasks and assessment. |
| **Lesson plans** | Learning objectives, timed activities, demonstrations, guided practice, feedback and assessment. |
| **Worksheets** | Student instructions, scaffolded exercises, testing and reflection, with separate teacher answers. |
| **PowerPoint presentations** | Lesson slides and teacher notes aligned with the lesson plan and worksheet. |
| **Topic and demo suggestions** | Suitable ideas, platforms and projects for students' readiness and available lesson time. |

Request one resource or combine them into a teaching pack.

## What each lesson includes

- A recommended platform and a practical fallback.
- **At least one task students can reasonably complete and have assessed during the lesson.**
- Success criteria and evidence to check each learning objective.
- Likely student difficulties, support and optional extensions.
- Inquiry, student choices, peer feedback and teacher feedback where appropriate.
- Relevant learning theories to explain teaching decisions.

The usual sequence is **Introduction → Example demo → Guided practice → Evaluation and improvement → Conclusion**. It can be adapted to the lesson.

Lesson plans use **Time | Content | Activity | Remarks**, unless the teacher supplies another format.

## Topics and curriculum support

- Computational thinking, block-based coding, pseudocode and text programming.
- AI literacy, vibe coding and supervised agentic development.
- Information and media literacy, digital citizenship and responsible technology use, taught separately or embedded in other lessons.
- Curriculum planning informed by Hong Kong, Singapore, US and UK contexts, with progression based on students' readiness.

**AI lessons:** map learning and assessment to selected OECD/EU AI literacy and UNESCO student AI competencies.

**Hong Kong secondary lessons:** connect to relevant Seven Learning Goals of Secondary Education. Teachers can also request selected elements from the **12 priority values and attitudes** and **20 major fields of national security education**. Connections appear in activities and assessment evidence, with a short mapping in teacher notes.

## How to use

Select **@Technology Teaching Designer** where it is installed, or use `$technology-teaching-designer` in a host that supports this invocation.

Provide the **topic, year level, lesson duration and resources needed**. Add students' prior knowledge, available devices, teaching language and a school template if useful.

### Example requests

**Lesson plan**

> Create a 40-minute S2 lesson on programming conditions. Students are beginners. Recommend a platform and include one completed assessed task.

**Worksheet and PowerPoint**

> Create a student worksheet, separate teacher answers and a PowerPoint for this lesson. Keep the examples and success criteria consistent.

**Curriculum map**

> Propose an S1–S3 technology curriculum covering block coding, Python, AI literacy and media literacy. Show a completed assessed task for every lesson.

**Hong Kong curriculum elements**

> Plan an S2 AI literacy lesson. Include Responsibility and Data Security, and explain connections to relevant Seven Learning Goals.

## Using this repository

This is a skill for an AI assistant, so it needs a host that supports skills. Keep `SKILL.md` and its accompanying folders together and follow your host's installation instructions.

Editable Word and PowerPoint files require suitable file-generation tools. Without them, the assistant can provide structured content. Review generated materials for accuracy, timing and suitability before teaching. Completing a task alone does not prove student understanding.
